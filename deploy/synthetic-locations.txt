# The ONLY coordinates permitted in Mist fixture and seed data.
#
# Containment rule 3's location clause. The EPIC-01 design said "no coordinate
# within N km of any contributor-supplied real location". That needs a list of
# real contributor locations, which would itself be personal data in the repo --
# the exact thing the rule exists to keep out. This inverts it: an ALLOWLIST of
# deliberately chosen cells instead of a denylist of real ones. Strictly
# tighter, and it stores nothing about anybody.
#
# Selection criteria: on land (a weather dashboard must have weather), in a
# low-population cell, in a named public place with no residents. Rounded to
# two decimals -- roughly 1 km, which is coarser than any dwelling.
#
# Format: lat,lon  # label      One per line. Blank lines and # comments ignored.
